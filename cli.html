CLI reference

The cxas binary is machine-first. Flags are long-form. Global options apply to every subcommand.

FlagDefaultMeaning

Exit codes

CodeMeaning
0Success
1Runtime / CES / lint / eval / drift failure
2Usage, missing location, TTY required, disabled feature

JSON envelope

{ "ok": true,  "command": "lint", "data": { } }
{ "ok": false, "command": "pull", "error": { "code": "LOCATION_REQUIRED", "message": "..." } }

Human format prints a short line instead of the envelope. Error lines look like error LOCATION_REQUIRED: ....

Location-bearing flags

Most CES-shaped commands accept:

--location <id>
--project-id <id>

Omitting --location on those commands is a usage error (exit 2, code LOCATION_REQUIRED).

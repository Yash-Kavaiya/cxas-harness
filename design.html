Constraints the specs freeze

  • No live CES or Gauntlet in the first implementation
  • Location mandatory; never silent "global"
  • Machine-first JSON CLI
  • Unknown proto enums must not panic
  • mdBook sidebar: Docs / Examples / Agent Skills / Core SDK (see book/)
  • This website is the published human docs surface

What this project is

cxas-harness is an independent Rust rewrite of Google Cloud's cxas-scrapi. It is a CLI (cxas) plus nine workspace crates. Design work followed Superpowers specs and plans dated 2026-08-15 under docs/superpowers/.

This checkout talks to a local catalog and in-process mocks, not live CES or GCP. That is intentional: tests never require a cloud project. Location is never silently defaulted to "global".

Machine-first CLI

JSON envelope on stdout, --no-input on by default, exit codes 0 / 1 / 2. Built for coding agents and CI.

Mandatory Location

Location has no Default. Empty is an error. __default_global__ is rejected. The literal "global" is allowed only when the caller passes it.

Issue-driven tests

The 25 cataloged cxas-scrapi issues each have a closer in the coverage map and an in-process unit test.

Nine crates

Parity, proto, core, utils, state, evals, lint, migration, and the cxas binary.

Honest status

Workspace tests pass against mocks. Commands that look like cloud operations record or read .cxas/catalog.json (or return mock fixtures). There is no live CES transport, no Vertex STT, and no Cloud RPC in this checkout. See Limits and honesty.
